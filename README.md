👥 HR Analytics Dashboard – Employee Attrition Analysis

An interactive Tableau dashboard developed to analyze employee attrition, workforce demographics, and job satisfaction. The dashboard transforms HR data into meaningful insights to help understand employee turnover and workforce trends.

Key Features:**
- Employee Count, Attrition Count, Attrition Rate, Active Employees, and Average Age KPIs
- Department-wise employee attrition analysis
- Employee distribution by age group
- Job satisfaction analysis by job role
- Education field-wise attrition analysis
- Gender-wise attrition rate across different age groups
- Interactive visualizations for HR performance analysis

Key Insights Analyzed:**
- Overall employee attrition and active workforce
- Attrition distribution across departments and education fields
- Employee demographics and age-group patterns
- Job satisfaction across different job roles
- Gender-based attrition trends
